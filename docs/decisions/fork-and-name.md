# Status

Accepted (2026-11-04) by the owner: fork Fractal; code name and visible
name "Nuntius".

# Context

The owner finds Fractal the best Matrix client on Phosh, but it shows no
notifications while it is closed. A new client would have to rebuild
end-to-end encryption, verification, sync and media before it matched
Fractal; Fractal already uses `matrix-rust-sdk`, which can decrypt a
single event in a separate process.

Fractal does not accept content generated by large language models in
any form (code, documentation, issues)[^contributing]. The work cannot
go upstream.

The Matrix.org Foundation's trademark policy (March 2026) does not allow
the mark in app names or combined with other words without
approval[^trademark], so "Matrix Chat" was not possible.

# Decision

- Fork Fractal on GitHub as `nexumia-de/nuntius`; `main` mirrors
  upstream, the fork lives on `phosh` ([fork workflow](../fork-workflow.md)).
- Code name, repository and visible name **Nuntius** (Latin for
  messenger); app id `de.nexumia.Nuntius`. "Matrix" appears only in
  `GenericName`, `Keywords` and descriptions, to say what the app works
  with.
- The About dialog and metainfo say that Nuntius is based on Fractal by
  the Fractal Team and not affiliated with it.

# Consequences

- Nuntius and Fractal can be installed side by side: settings, the
  keyring schema (`xdg:schema` is the app id) and the Flatpak sandbox
  are separate.
- The fork carries its changes forever and merges upstream daily; the
  diff against upstream is kept small.
- The icon is still Fractal's (CC-BY-SA-4.0); an own icon is a
  follow-up.
