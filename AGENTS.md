# Nuntius

Matrix chat app for Phosh phones and the desktop: a fork of
[Fractal](https://gitlab.gnome.org/World/fractal) (GPL-3.0-or-later)
whose first goal is push notifications through UnifiedPush and ntfy
while the app is closed. The shared rules in ../phosh-toolkit/AGENTS.md
apply as well, with the exceptions below. Knowledge of this fork:
[docs/index.md](docs/index.md).

This file replaces upstream's `AGENTS.md` on `phosh`; upstream's rules
for contributions are in `CONTRIBUTING.md` and recorded in
[docs/fork-workflow.md](docs/fork-workflow.md).

## Branches

- `main` is identical to upstream `main` on GNOME's GitLab. Never commit
  to it; `.github/workflows/sync-upstream.yml` mirrors it daily and opens
  a pull request `main` -> `phosh`, merged with a merge commit.
- `phosh` is the default branch: upstream plus the fork's files and
  changes. Work happens on branches from `phosh` and comes in by pull
  request; the owner merges.

## Upstream

- Fractal does not accept content generated by large language models
  (`CONTRIBUTING.md`, "LLM Contributions"). Nothing from this fork goes
  upstream: no merge requests, issues or comments written by an agent.
- Keep the diff against upstream small so the daily merges stay easy:
  change upstream files only where needed, keep upstream's file names
  (`org.gnome.Fractal.*` sources with `base_id`), put new code in new
  files where possible, and follow upstream's style (`rustfmt`, clippy,
  `CONTRIBUTING.md`).

## App rules

- Code name, repository and visible name: Nuntius. App id:
  `de.nexumia.Nuntius`. Never present the app as Fractal or as official
  Matrix software; "Matrix" appears only to say what it works with
  ([decision](docs/decisions/fork-and-name.md)).
- The toolkit's Python packages, UI rules for new screens and accent
  rules apply to code written here; upstream's existing UI stays as it
  is unless a change is needed on the phone.
- Fractal needs GTK ≥ 4.20 and libadwaita ≥ 1.8: build it with
  flatpak-builder and `build-aux/de.nexumia.Nuntius.json` (GNOME 51
  SDK), not on the Ubuntu 24.04 host
  ([dev environment](docs/dev-environment.md)).
